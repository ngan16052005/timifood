## Chạy server trên local
- Khởi động server: npm run start:cluster
- Tắt server: npx pm2 stop all

## Chạy server trên internet với ngrok
- Vào ngrok.exe để tạo tunnel với địa chỉ:" ngrok http --domain=dejected-radio-myspace.ngrok-free.dev 3500 "

## Làm sạch cổng 3500
- Mở Command Prompt (Admin):
    taskkill /f /im node.exe
